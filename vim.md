## advance vim usage 
| Command                      | Description                        |
|------------------------------|------------------------------------|
| `$`                          | End of the line                    |
| `shift+G`                    | End of the file                    |
| `0`                          | Start of the line                  |
| `gg`                         | Start of the file                  |
| `i`                          | Insert at cursor                   |
| `a`                          | Insert after cursor                |
| `hjkl`                       | Move around                        |
| `yy`                         | Single line copy                   |
| `3yy`                        | Multiple line copy (copy 3 lines)  |
| `dd`                         | Cut the line                       |
| `5dd`                        | Multiple cut lines (cut 5 lines)   |
| `p`                          | Paste                              |
| `u`                          | Undo                               |
| `/`                          | Search                             |
| `^name$`                     | Search with regex                  |
| `n`                          | Next line in search                |
| `v`                          | Visual mode                        |
| `:set nu`                    | Show number lines in Vim           |
| `:set list`                  | Show special characters in Vim     |
| `q`                          | Quit                               |
| `q!`                         | Force quit                         |
| `wq`                         | Write and quit                     |
| `wq!`                        | Force write and quit               |
